# IEEE Access and APA 7 Formatting Audit

Audit completed October 29, 2026.

## IEEE Access submission candidate

- Built in the official IEEE Access two-column Word template.
- Matching Word and PDF files rendered to five pages.
- Official template styles control body text, headings, references, headers, and footers.
- Table captions appear above each table as `TABLE` plus a Roman numeral and descriptive title.
- All seven tables are called out in numerical order in the manuscript.
- Table text is 8 point for legibility within the official two-column layout.
- References [1]-[14] are present and each is cited in the article.
- AI assistance is disclosed with systems, citations, affected sections, and the author's review responsibility.
- The DOI is marked as unassigned pending acceptance.

## APA 7 professional-paper version

- One-inch margins, page numbers, all-caps running head, and 12-point Times New Roman are used.
- Text, headings, table numbers/titles, notes, and references are double-spaced with no extra paragraph spacing.
- The table bodies use the same 12-point Times New Roman font; single spacing inside cells is used only for effective table layout, as APA permits.
- The body begins with the paper title and does not repeat an `Introduction` heading.
- Level 1 and Level 2 headings follow APA placement and emphasis.
- Table numbers are bold above italicized table titles; tables avoid vertical rules.
- The reference list begins on a new page, is alphabetized, double-spaced, and uses 0.5-inch hanging indents.
- Stand-alone works, report titles, journal names, and volume numbers use APA italics where applicable.
- All 14 reference entries have corresponding in-text citations, and all seven tables have in-text callouts.

## Visual verification

Every rendered page of both versions was inspected. No clipped text, overlapping elements, broken tables, or missing pages were found in the final files.

## Author checks that remain external to formatting

- Recheck journal portal requirements on the actual submission date.
- Confirm the complete author list, originality, conflicts, and overlapping works.
- Confirm the public ORCID profile and IEEE account connection.
- Run the journal's preflight tool and inspect the portal-generated proof.
- Verify URLs, DOI resolution, and retraction status immediately before submission.
